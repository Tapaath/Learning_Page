# Thai Wah Learning Hub

หน้า Learning สำหรับ Intranet ของ Thai Wah ดูแลโดย T&OD

## โครงสร้าง
- `index.html` หน้าเว็บ (HTML/CSS/JS ไฟล์เดียว ไม่ต้อง build)
- `images/` ภาพประกอบและโลโก้
- `guides/` คู่มือ PDF ที่ลิงก์จากหน้า

## เปิดใช้งานด้วย GitHub Pages
Settings › Pages › Source: Deploy from a branch › เลือก `main` / root

## หมายเหตุ
- ฟอนต์โหลดจาก Google Fonts (Prompt, Kanit, Rubik)
- ภาพประกอบมาจากชุด template ที่ดาวน์โหลดมา ตรวจเงื่อนไขไลเซนส์ก่อนเผยแพร่สาธารณะ
